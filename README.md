# research-models

[Environmental changes, co-extinction, and patterns in the fossil record](https://arxiv.org/abs/cond-mat/9804102) Luis A. N. Amaral (MIT), Martin Meyer (BU) 1998
The finding here takes a trophic network organised in layers. Each layer feeds only on part of the layer below it. Adds a model for speciation. And extintion event that cascade, (if enough of your food fails then you also go extinct). It shows the size of these cascading failures follows a power law in a way that has very suggestive parallels with the scale of extinction events in the paleological record.
